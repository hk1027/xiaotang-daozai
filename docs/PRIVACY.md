# 隐私与安全

## 本机数据

岛仔默认在 `%APPDATA%\Daozai` 保存用户设置、待办、本机日程及提醒设置、饮水记录、置物文件路径、连接元数据以及忽略的邮件日程标识。环境变量 `DAOZAI_DATA_DIR` 可指定另一目录。置物架保存原文件路径，不复制文件正文。本机日程不上传到工作日历。

邮箱和日历密码通过 Windows 凭据管理器保存；独立 Gemini 会话与豆包网页会话使用当前 Windows 用户的 DPAPI 加密。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。当前邮件记录保存在内存中；不要将运行中的内存转储公开分享。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，本地队列缺少网易云曲目信息时按歌曲 ID 向网易云查询；系统和本机均未提供封面时，会用歌名和歌手向网易云搜索并下载匹配的专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

音乐识别不完整时，本地诊断日志可能包含播放器名称、歌名、歌手和歌曲 ID。视频或类型未识别的媒体只记录来源与缺少的信息。导出的诊断包由用户自行选择是否分享。

Windows 下的工作日历连接使用系统 TLS 和证书信任库，保留证书有效期及服务器名称校验。自签证书或私有 CA 需要先由用户或管理员加入 Windows 信任库。日历诊断日志只记录服务类型、同步范围、错误分类和数量统计，不记录服务器地址、凭据或日程正文。

开启天气模块后，程序会访问 Open-Meteo 获取天气；手动指定城市时向其地理编码服务发送城市名，自动定位时优先通过 `https://ipwho.is/` 获取网络出口的大致城市与坐标，失败时尝试 `https://free.freeipapi.com/api/v1/json`，再用坐标查询天气。请求优先直连，必要时可回退到用户已配置的系统或环境变量代理，两个定位服务的直连尝试先于代理尝试。自动刷新间隔为 15 分钟，关闭天气模块后不再发起新一轮查询，在途结果不更新界面或缓存。天气查询不读取账号、邮箱或日程数据。各城市最近一次天气快照保存在数据目录的 `weather-cities.json`，供断网时查看；系统 TUN/VPN、代理和共享网络出口仍可能影响定位位置。

切换为和风天气后，城市搜索、实况和七日预报只访问用户提供的官方 `qweatherapi.com` 专属域名，使用 HTTPS 和 `X-QW-Api-Key` 请求头，不跟随重定向。Key 仅保存在 Windows 凭据管理器，不写入普通设置、日志、诊断包或天气缓存。和风城市需重新手动选择，不复用 Open-Meteo 的坐标或自动定位；默认来源及其已保存城市保持不变。

和风实况约每 60 分钟、预报约每 6 小时刷新，仅调度当前城市；天气缓存与请求计数分别保存在 `qweather-cache.json` 和 `qweather-usage.json`，来源及用户选择保存在 `weather-provider.json`。本机每自然月最多 5,000 次出站尝试，搜索、连接测试、手动刷新及失败尝试统一先记账再发送；计数无法保存时停止请求。关闭天气页面模块后停止和风新请求并丢弃在途结果，状态组件开关只控制常驻显示。和风账号的免费额度由同一账号的其他设备和项目共享，岛仔无法限制其他应用的用量。

天气连接诊断保存在 `diagnostics/weather-network.log`，只记录请求阶段、服务域名、直连或代理、耗时和错误类别，不记录 IP、经纬度、城市查询参数、代理地址或凭据。每份日志最多 256KB，轮转保留上一份，不会自动上传。

岛仔启动后会自动访问 GitHub 的公开发布接口，成功检查后间隔 24 小时，失败后间隔 1 小时重试。也可以手动点击「检查更新」。请求头包含岛仔版本号，不发送本地设置、邮箱或日程数据。下次检查时间和已提醒的版本号保存在本机。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\Daozai\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

程序不使用统一的岛仔云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

中转站的自定义查询脚本与其中的凭据由当前 Windows 用户的 DPAPI 加密保存；执行脚本时仅访问所配置站点的 HTTPS 接口，不向其他站点发送凭据。普通 API Key 与 New API 用户 Token 仍保存在 Windows 凭据管理器中。

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由岛仔自己的安全存储管理。不要把 Cookie、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。
